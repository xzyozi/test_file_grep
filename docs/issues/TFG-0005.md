# [TFG-0005] src/grep/interface.py にパス検証関数 is_valid_file_path を追加し、単体テストを作成する

- **検出テーマ**: architecture / robustness
- **重要度**: High
- **関連Issue**: 該当なし
- **起票ステータス**: `stage:ready` (方針確定・tasks.md 登録完了)

## 1. 概要・背景
ファイルパスの妥当性検証を一貫して行うため、`src/grep/interface.py` にユーティリティ関数 `is_valid_file_path` を追加し、単体テストを整備する。

## 2. 対象ファイル (Target Files)
- `src/grep/interface.py`
- `tests/test_interface.py`

## 3. 要求事項 (Requirements)
1. `src/grep/interface.py` に `is_valid_file_path(path: str | Path | None) -> bool` を定義する。
2. None や空文字、不正なパス（存在しない、またはパス構文エラー）を安全に判定し、例外を送出せず bool を返すこと。
3. `tests/test_interface.py` に正常系および異常系（空文字列、None、不正文字など）のテストケースを作成すること。
4. 既存テストおよび Ruff / Mypy チェックをパスすること。

## 4. 完了定義 (Definition of Done)
- [ ] `is_valid_file_path` が `src/grep/interface.py` に実装されていること。
- [ ] 単体テストが作成され、全テストがパスすること。
- [ ] Ruff / Mypy の静的解析を通過すること。
